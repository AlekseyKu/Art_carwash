# Фича 01: Камера на въезде + ANPR → клиент на кассе

**Статус:** backlog — ждём покупку камеры (UI на кассе скрыт)

## Цель

При въезде автомобиля камера распознаёт госномер. На кассе справа от основного блока показываются данные клиента (если есть в базе) или заготовка «новый клиент» по номеру.

## Почему отложено

Панель клиента/ANPR убрана с кассы до появления железа. Бэкенд (API, `plate_events`, нормализация номера) и компонент `ClientSidePanel` сохранены — подключаем снова после покупки IP-камеры / ANPR.

## UX (когда вернём)

```
┌─────────────────────────────┬──────────────────────┐
│ Посты / услуги / скидка     │ Клиент (въезд)       │
│ итого / оплата              │ Госномер             │
│                             │ Имя, телефон         │
│                             │ Визиты / лояльность  │
│                             │ [Привязать к заказу] │
└─────────────────────────────┴──────────────────────┘
```

- Правая колонка на кассе после PIN.
- Обновление по событию ANPR (polling `GET /api/anpr/latest`).
- Ручной ввод/поиск госномера — запасной путь без камеры.
- Кнопка эмуляции въезда (для теста без железа).

## Поток данных

```
Камера/ANPR → POST /api/anpr/event → plate_events + lookup clients
Касса ← GET /api/anpr/latest (poll)
Касса → PUT /api/orders/:id/client (привязка)
```

## Нормализация номера

Пробелы и дефисы убираются, буквы в верхний регистр (латиница и кириллица), хранение в `clients.plate_number` в нормализованном виде.

## API

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/anpr/event` | Событие распознавания `{ plate, confidence?, snapshotUrl?, source? }` |
| GET | `/api/anpr/latest` | Последнее событие + клиент (если найден) |
| GET | `/api/clients/by-plate?plate=` | Поиск клиента |
| POST | `/api/clients` | Создать/обновить клиента |
| PUT | `/api/orders/:id/client` | Привязать `clientId` к черновику |

## Железо / адаптер

- IP-камера + внешний ANPR (HTTP webhook на `/api/anpr/event`).
- Либо мост, который шлёт уже распознанный номер.
- До камеры: эмулятор `POST /api/anpr/event`.
