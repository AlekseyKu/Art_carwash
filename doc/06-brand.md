# Бренд: Автомойка АРТ

## Шрифт

**Montserrat** (Google Fonts, кириллица) — весь UI.

## Киоск (касса / админ) — текущие токены

Пока **не меняем** в `apps/web`. Перенос на палитру PWA — отдельный шаг.

```css
:root {
  --brand-primary: #6A5ACD;
  --brand-primary-hover: #5A4BB8;
  --brand-silver: #A9A9A9;
  --brand-silver-soft: #D8DADF;
  --ink: #1E1F24;
  --muted: #6B6F78;
  --surface: #F3F4F7;
  --surface-elevated: #FFFFFF;
  --success: #2F9E6B;
  --danger: #C43C3C;
  --warning: #C48A1A;
  --font: "Montserrat", system-ui, sans-serif;
}
```

- Primary — CTA, активный пост, акцент бренда.
- Silver — вторичные акценты, разделители.
- «Автомойка АРТ» — заметный сигнал на экране PIN и в шапке кассы.

## PWA — тёмно-красный + графит

База: **графит `#303236`** (текст, хром, сплэш) + **тёмно-красный** (CTA, активная вкладка, акценты).  
`--danger` оставляем более ярким (`#C43C3C`), чтобы ошибки не сливались с брендом.

Сплэш: фон графит, лого белый / светло-серебряный, тонкая красная подложка или буква.

### Варианты оттенка (красный)

| | Название | Primary | Hover | Характер |
|---|----------|---------|-------|----------|
| **A (рекомендуем)** | **Гранат** | `#8E1D2C` | `#751824` | Холодный тёмно-красный, хорошо стыкуется с холодным графитом, не «пожарный» |
| B | Киноварь | `#9B1B1B` | `#7E1616` | Классический автомобильный красный, чуть теплее графита |
| C | Бордо | `#6F1D2B` | `#581722` | Более винный / премиум, спокойнее на большом экране |

Мягкий фон под чипы/бейджи: смешать primary с белым (~12%): Гранат `#F4E8EA`, Киноварь `#F5E8E8`, Бордо `#F1E7E9`.

### Токены PWA (набор A — Гранат)

Стартовые токены для `apps/pwa`. Смена на B или C — подставить primary/hover/soft, графит не трогать.

```css
:root {
  --brand-primary: #8E1D2C;
  --brand-primary-hover: #751824;
  --brand-primary-soft: #F4E8EA;
  --brand-graphite: #303236;
  --brand-graphite-muted: #5C6066;
  --brand-graphite-soft: #D4D6D9;
  --ink: #303236;
  --muted: #5C6066;
  --surface: #F2F2F3;
  --surface-elevated: #FFFFFF;
  --success: #2F9E6B;
  --danger: #C43C3C;
  --warning: #C48A1A;
  --font: "Montserrat", system-ui, sans-serif;
}
```

### Как сочетать

- Кнопки / активная вкладка: primary на белом тексте.
- Нижняя навигация: иконки графит, активная — primary.
- Поля ввода: обводка `graphite-soft`, фокус — primary.
- Вторичные кнопки: обводка графит, текст графит, без заливки красным.
- Карточки прайса: поверхность `#FFFFFF` на `#F2F2F3`.
