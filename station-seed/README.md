# Seed БД для рабочей станции

Снимок локальной SQLite с каталогом (услуги, доп.услуги, цены, классы и т.д.).

## Важно: экспортировать seed с dev

Пока открыт `pnpm dev`, изменения часто лежат в `data/local.db-wal`, а не в `local.db`.
Перед копированием в `station-seed` нужно слить WAL (checkpoint) или остановить API и убедиться, что в seed попали актуальные данные.

## Куда копировать на кассе

1. **Полностью закройте** приложение кассы (диспетчер задач: нет «Автомойка АРТ» / node).
2. Узнайте **реальный** каталог данных — в `%APPDATA%\ArtCarwash-POS\update.log` строка `userData=...`.  
   Иногда это не `ArtCarwash-POS`, а старая папка (`автомойка-арт` и т.п.) — копируйте туда, в подпапку `data\`.
3. В `...\data\` **удалите все три файла**:
   - `local.db`
   - `local.db-wal`
   - `local.db-shm`
4. Скопируйте только `station-seed/local.db` из репозитория.
5. Запустите кассу.

Файл в git обновляйте после правок каталога на dev (с checkpoint WAL).
