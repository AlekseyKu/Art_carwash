# Seed БД для рабочей станции

Снимок локальной SQLite с каталогом (услуги, доп.услуги, цены, классы и т.д.).

## Две разные БД в `data/`

| Файл | Сервис | Что хранит |
|------|--------|------------|
| `local.db` | **local-api** (касса/админ) | каталог, цены, заказы, мойщики, смены |
| `cloud.db` | **cloud-api** (отчёты `/reports`) | заказы, прилетевшие через sync outbox |

На рабочей станции Electron обычно есть только `local.db`. `cloud.db` для кассы не нужен и **не копируется** со станции.

Синхронизация каталога между ПК = копирование `local.db` (с checkpoint WAL), а не `cloud.db`.

## Важно: экспортировать seed с dev

Пока открыт `pnpm dev`, изменения часто лежат в `data/local.db-wal`. Перед копированием в `station-seed` сделайте checkpoint или остановите API.

## Куда копировать на кассе

1. **Полностью закройте** приложение кассы.
2. Реальный каталог — строка `userData=...` в `update.log`.
3. В `...\data\` удалите `local.db`, `local.db-wal`, `local.db-shm`.
4. Скопируйте только `station-seed/local.db`.
5. Запустите кассу.
