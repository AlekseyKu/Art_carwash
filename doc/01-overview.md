# Автомойка АРТ — обзор

Кассовое приложение для одной автомойки (2 поста) на Windows мини-ПК с возможностью открыть тот же UI на Android позже.

## Цели

- Оформление услуг мойщиком с расчётом суммы, скидкой и оплатой (наличные / карта / СБП QR).
- Админка по мастер-коду: услуги, цены, скидки, мойщики, настройки терминала, аналитика.
- Облачные отчёты для собственника с телефона.
- **Офлайн на мойке критичен** — касса работает без интернета.

## Роли

| Роль | Вход | Возможности |
|------|------|-------------|
| Мойщик | PIN 4–6 цифр | посты, услуги, скидки, оплата |
| Админ | мастер-код | каталог, мойщики, терминал, аналитика |
| Собственник | облачный пароль | отчёты read-only |

## Платформа

Local-first: локальный API + SQLite на мини-ПК; облако — sync для отчётов.
