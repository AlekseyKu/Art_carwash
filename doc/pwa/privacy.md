# Политика обработки персональных данных

**Статус:** draft (текст в проде; юр. ревью заказчика по желанию)  
**Оператор:** Автомойка у ЖД (г. Ступино)  
**Версия документа:** `2026-08-30`  
**Приложение:** клиентское PWA «Автомойка у ЖД»

Это рабочий черновик для продукта (152-ФЗ). Перед продакшеном заказчик может заменить текст; при смене текста **обязательно** поднять `privacy_policy_version` и запросить повторное согласие у новых регистраций (и при существенных изменениях — у существующих пользователей).

---

## 1. Общие положения

1.1. Настоящая Политика определяет порядок обработки персональных данных пользователей мобильного веб-приложения «Автомойка у ЖД» (далее — Приложение).

1.2. Используя Приложение и регистрируя учётную запись, пользователь подтверждает согласие с условиями Политики в редакции, указанной при регистрации (`privacy_policy_version`).

1.3. Оператор обрабатывает персональные данные на законной и справедливой основе, ограничиваясь целями, заявленными в Политике.

---

## 2. Какие данные обрабатываются

| Категория | Примеры | Обязательность |
|-----------|---------|----------------|
| Учётные данные | номер телефона, хэш пароля | да, для регистрации |
| Профиль | имя (если указано) | нет |
| Транспорт | госномер, класс автомобиля, кличка авто | для записи / истории |
| Записи на мойку | дата/время, выбранные услуги, статус | при записи |
| Технические | токен сессии, дата согласия на ПДн, версия Политики | да |
| История визитов | сведения об оплаченных мойках, связанные с телефоном/госномером | после визита на мойке |

Оператор **не** запрашивает паспортные данные, ИНН и платёжные реквизиты карты в Приложении первой версии (оплата — на мойке).

---

## 3. Цели обработки

- создание и обслуживание учётной записи;
- показ актуального прайс-листа и сведений о мойке;
- запись на мойку и информирование о статусе записи;
- идентификация клиента на кассе (телефон / госномер);
- связь с клиентом по вопросам записи и обслуживания;
- исполнение требований законодательства РФ;
- улучшение работы Приложения (агрегированная статистика без продажи данных третьим лицам в рекламных целях).

---

## 4. Правовые основания

- согласие субъекта персональных данных (ст. 6 ч. 1 п. 1 152-ФЗ) — при регистрации;
- исполнение договора / оферты на оказание услуг мойки — при записи и визите;
- законные интересы оператора — обеспечение безопасности учётных записей и предотвращение злоупотреблений.

---

## 5. Хранение и передача

5.1. Данные учётной записи и записей хранятся на сервере оператора (облачный API). Каталог и операционные данные мойки синхронизируются со станцией обслуживания.

5.2. Доступ имеют уполномоченные сотрудники мойки в объёме, необходимом для приёма клиента и оказания услуг.

5.3. Передача третьим лицам — только если это требуется законом, либо для работы инфраструктуры (хостинг), при условии конфиденциальности.

5.4. Пароль хранится только в виде криптографического хэша; оператор не может восстановить исходный пароль.

---

## 6. Сроки хранения

- учётная запись — пока пользователь не удалит её или не будет удалена по запросу / по основаниям закона;
- записи и история визитов — в сроки, необходимые для обслуживания и учёта (не дольше, чем требуют цели обработки и закон);
- сессии — до выхода из аккаунта или истечения срока действия токена.

---

## 7. Права пользователя

Пользователь вправе:

- получить сведения об обработке своих данных;
- требовать уточнения, блокирования или удаления данных, если они неполные, устаревшие или обрабатываются незаконно;
- отозвать согласие (это может сделать невозможным использование Приложения);
- обжаловать действия оператора в Роскомнадзор или суд.

Запросы: по телефону мойки **+7 985 274-14-30** или лично на мойке (г. Ступино).

## 8. Меры защиты

Оператор принимает организационные и технические меры: разграничение доступа, передача по HTTPS (в продакшене), хранение паролей в виде хэша, ограничение доступа сотрудников.
