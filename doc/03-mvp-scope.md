# MVP — границы и экраны

## Касса (мойщик)

1. PIN → сессия мойщика.
2. Выбор поста 1/2; два параллельных черновика по постам.
3. Мультивыбор услуг, автосумма.
4. Скидка из каталога.
5. Оплата: СБП / наличные / карта.
6. Статусы: `draft` → `awaiting_payment` → `paid` | `cancelled`.
7. Блок лояльности — «В разработке».

## Админ (мастер-код)

- CRUD услуг, скидок, мойщиков.
- Настройки терминала (поля под адаптер).
- Аналитика: день / месяц; услуги, посты, способы оплаты.
- Смена мастер-кода.

## Не в MVP

Смешанная оплата, возвраты, смены, премии, чек 54-ФЗ.

## Критерии готовности этапа 1

- [x] PIN и мастер-код
- [x] CRUD услуг/скидок; ₽ на UI, копейки в БД
- [x] Заказ на пост, наличные → paid + аналитика
- [x] Эмулятор карты; СБП офлайн недоступен
- [x] Индикатор офлайна
- [x] Заглушка лояльности; бренд АРТ
