### A12 — акции в админке (детализация)

Админ задаёт правила подсказок и автобонусов, например:

- «Добавь мойку ковров → кофе бесплатно»
- «Кузов+салон → скидка 200 ₽ на аромасаше»
- «3-й визит за месяц → кофе в подарок»

Поля правила (черновик модели):

- название, активна, период действия;
- условие: услуга(и) в заказе / сумма / кол-во визитов / тег клиента;
- действие: добавить позицию с ценой 0, скидка %, фиксированная скидка, только подсказка кассиру;
- текст подсказки на кассе («Предложите мойку ковров — кофе бесплатно»).

### P12 — доп. продажи кофе

- Сделано: вкладки каталога (`catalog_tabs`), на кассе «Услуги» / «Товары», в админке отдельные разделы + «Вкладки» для новых.
- Seed товаров: кофе, чай, вода.
- Дальше: раздельная аналитика «мойка» vs «бар»; акции P13.

### P13 — акции и подсказки кассиру

Примеры на кассе:

1. Баннер/карточка: «Добавьте мойку ковров — кофе бесплатно».
2. Если кассир добавляет «Мойка ковров» — в заказ автоматически (или по кнопке «Применить») попадает «Кофе» с ценой 0.
3. Если условие уже выполнено — подсказка «Акция применена» + зелёная отметка.
4. Подсказки не перекрывают оплату; можно скрыть / отклонить с причиной (для аналитики отказов).

Связка с админкой: только активные правила из A12; локальный каталог (offline-first).
