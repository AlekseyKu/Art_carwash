# Seed БД для рабочей станции

Снимок локальной SQLite с каталогом (услуги, доп.услуги, цены, классы и т.д.).

## Куда копировать на кассе

1. Закройте приложение кассы.
2. Сделайте бэкап текущего файла (если есть):
   `%APPDATA%\ArtCarwash-POS\data\local.db`
3. Скопируйте `local.db` из этой папки в:
   `%APPDATA%\ArtCarwash-POS\data\local.db`
4. Запустите кассу.

Файл в git обновляйте вручную после правок каталога на dev (`data/local.db` → сюда).
